# きょうの単語

毎日ルーレットで決まる英単語を「会話で使って」覚える英語学習アプリ（PWA）。

## 機能
- **ルーレット**: 1日N語（設定で1〜5語）をルーレットで決定。1日の会話で実際に使えたら「会話で使った」を押して消す（押し間違えたら取り消し可）
- **ホーム**: 連続学習日数・今週のカレンダー・7日間グラフ・学習記録
- **辞書**: 約32,000語（固有名詞・複合語を含む）。英語の前方一致／日本語の意味から検索、発音読み上げ
- **わからない単語メモ**: 自由入力・辞書から追加・テストで間違えた単語を追加。テストで2回連続正解すると自動で「覚えた」に
- **単語テスト**: 10問4択（英→日 / 日→英）。レベル別・メモ・使った単語・ミックス

データはすべて端末内（localStorage）に保存されます。

## パソコンで動かす
```bash
python -m http.server 8765
```
http://localhost:8765 を開く。

## スマホで使う
1. このフォルダを GitHub Pages や Netlify などの HTTPS ホスティングにアップロード
2. スマホのブラウザで開き「ホーム画面に追加」（iPhone は Safari の共有ボタンから）
3. アプリのように全画面で起動、オフラインでも動作

## 辞書データ
- 英和辞書: [EJDict-hand](https://github.com/kujirahand/EJDict)（パブリックドメイン / CC0）
- レベル分け・マイナー語の除外: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) の出現頻度順位（上位100,000語まで）

| レベル | 頻度順位 | 目安 |
|---|---|---|
| Lv1 | 〜1,500 | 中学英語 |
| Lv2 | 〜4,000 | 高校・英検2級 |
| Lv3 | 〜9,000 | 大学受験・TOEIC 600〜 |
| Lv4 | 〜20,000 | TOEIC 800〜・英検準1級 |
| Lv5 | 〜45,000 | ちょいマイナー |
| Lv6 | 〜100,000 | マニア |

作り直すとき: `python -I tools/build_dict.py <EJDictフォルダ> <en_full.txt>`
